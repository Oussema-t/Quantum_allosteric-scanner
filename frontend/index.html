Site-potential analysis (GNM)

Five structure-based descriptors per residue (z-scored). “active site − bulk” shows how elevated each term is at the active site vs the rest of the protein; the per-residue profiles reveal where rigidity, coupling and slow-mode participation peak across the chain — structural candidates for functional/allosteric regions. Use the 3D “Color by” menu to paint the structure by any term.

ℹ︎ How to read these values

Each descriptor is a z-score (standard deviations from the protein's mean). “active site − bulk” = how the active site compares to the rest: + elevated there, − depleted. A bar is red only if a permutation test says the difference is unlikely by chance (p<0.05).

  • V_B · B-factor flexibility — crystallographic mobility. − = more rigid / ordered (a stable core); + = more flexible.
  • V_T · terminal / exposure — chain-end + solvent exposure. − = more buried / central; + = more exposed / peripheral.
  • V_R · rigidity — high contacts + clustering, low fluctuation. + = a rigid hub; − = floppy.
  • V_C · dynamic coupling — how correlated its motion is with the rest. + = a communication hub (allosteric signal carrier); − = dynamically isolated.
  • V_M · slow-mode participation — share in the slowest collective motions. + = drives global hinge/domain motion; − = in the static body.

Contact-Laplacian spectrum (λ): the network's vibrational modes. Low λ (near 0) = slow, large-scale collective motions (hinges / domains) — these carry allosteric signals over long range; lots of low-λ density (a small “spectral gap”) means a softer, more deformable network. High λ = fast, local fluctuations. (One λ≈0 per connected chain.)

Connectivity change apo→holo (DDM · rewiring · ΔDCC + morph)

How the residue network reorganizes when the drug binds (topology only, no MD). DDM = distance-difference matrix (red = move apart, blue = move closer); rewiring = contacts formed (+1) / broken (−1); ΔDCC = change in dynamic cross-correlation (the coupling that underlies allosteric communication). Overlay lines: teal = active site, purple = drug-binding residues.

ℹ︎ How to read these values

Everything compares the holo (drug-bound) to the apo structure on their shared residues — i.e. what the drug changed.

  • DDM — distance-difference matrix (Å): for each residue pair, |distance|holo − |distance|apo. red = moved apart, blue = moved closer. Off-diagonal red/blue blocks = whole regions shifting against each other (a hinge / domain motion); it's frame-independent (no alignment needed).
  • Contact rewiring: which contacts change at the cutoff — +1 = formed on binding, −1 = broken. Clusters mark where the network physically re-wires.
  • ΔDCC — dynamic cross-correlation change: change in how correlated two residues' motions are. + = more coupled on binding (a new communication channel), − = decoupled. This is the dynamic connectivity that underlies allosteric signalling.

Summary numbers: max |Δdist| = the single largest Cα move; contacts formed / broken = how much the contact network rewired; mean |ΔDCC| = overall change in dynamic coupling; most-reorganized residues = largest per-residue distance change (DDM row-norm).

Quantum-seed readiness — is the active site safe to run the quantum algorithm from?

Before seeding a quantum walk at the active site, check it's connected + rigid enough to carry signal (the walk runs on the same Kirchhoff operator as the GNM, so its connectivity predicts propagation). Verdict per state: SAFE, PARTIAL (seed the strong subset), RISKY (signal stays local). The apo→holo shift reads whether the drug locks/decouples the site (deactivation) or mobilises it (activation).

ℹ︎ How to read these values
  • degree = contacts in the Cα network (low → poorly embedded, signal can't leave); coupling = dynamic coupling to the whole protein (low → isolated); rigidity = rigid-core score (low / high MSF → floppy seed dissipates the walk); modeled = interpolated coordinates (a guess → vetoed).
  • distal-reach enrichment = how much more the walk's amplitude (average-mixing matrix) concentrates on residues >12 Å from the seed vs a uniform spread — size-invariant (works for an 88-mer or a 950-mer). >1.2× good, <0.5× trapped.
  • Verdict: SAFE = most seed residues reliable and enrichment ≥1.2× · PARTIAL = some weak (use recommend seed) · RISKY = mostly weak or <0.5× → predictions low-confidence (expand the seed to the binding pocket).
  • apo→holo shift uses raw descriptors (not z-scores, which would drift with the structure), and each Δ is significance-tested against a 2σ bootstrap noise floor (random residue subsets) → marked ✓ >2σ or ns. The shift is measured at the active site (functional readout) and at the drug-binding pocket (computed from the holo structure; orthosteric vs allosteric is auto-detected from how far the pocket sits from the active site).
  • Mechanism (hypothesis, elastic-network not assay): rigidify the drug-binding site (MSF ↓) and the active site loses coupling or shows a global mode shift → deactivation (inhibitor-like); raises coupling without rigidifying → activation; otherwise ambiguous.

② Quantum solving — allosteric prediction + trap pre-flight

Allosteric site prediction — CTQW seeded at the active site

Propagate a continuous-time quantum walk from the active site and rank residues by transfer. Occupation = time-averaged occupation (residues inside the pocket); pathway = Green's-function drivers (often outside it). P@5 = the top-5 vs the holo drug pocket — validation only, the pocket never reaches the predictor. Operator = the documented disorder-suppressed winner, un-tuned (not the per-target-optimized pipeline). teal = active-site seed, pink = predicted allosteric top-5.

Phase-2 pre-flight, before running the allosteric walk: map the residues where a continuous-time quantum walk would stall — localized dead-end modes of the transport operator. This is a connectivity/failure diagnostic, not an allosteric-site prediction. teal = active site (the walk's seed).

ℹ︎ How to read these — and the honest scope
  • Operator traps = localized eigenstates of the graph operator H (high inverse participation ratio, confined away from their output neighbours). A property of H's eigenvectors — no time evolution, no seed.
  • Classical baseline: a plain lowest-degree threshold already reproduces most traps — so this is reported as a classical connectivity diagnostic, not a quantum result. The dynamical gate keeps only traps that beat a degree-matched time-averaged-return control.
  • Seed-coupled traps = the subset the walk seeded at the active site actually feeds (weighted by the seed's overlap with each localized mode). These are the dead-ends the real active-site walk hits.
  • Scope (fact-checked): "trap" = a localized eigenstate (not an absorbing sink); boundary-confinement is a probability ratio (not a signed-amplitude dark state); on a finite protein graph this is finite-size localization, not a true Anderson transition; near-degenerate multiplets are excluded (basis-arbitrary). Refs: Bell&Dean 1970 / Wegner 1980 (IPR); Mülken&Blumen 2011 (CTQW localization); Godsil 2013 (average mixing).
