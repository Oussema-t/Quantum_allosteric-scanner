Site-potential analysis (GNM)

Five structure-based descriptors per residue (z-scored). “active site − bulk” shows how elevated each term is at the active site vs the rest of the protein; the per-residue profiles reveal where rigidity, coupling and slow-mode participation peak across the chain — structural candidates for functional/allosteric regions. Use the 3D “Color by” menu to paint the structure by any term.

ℹ︎ How to read these values

Each descriptor is a z-score (standard deviations from the protein's mean). “active site − bulk” = how the active site compares to the rest: + elevated there, − depleted. A bar is red only if a permutation test says the difference is unlikely by chance (p<0.05).

  • V_B · B-factor flexibility — crystallographic mobility. − = more rigid / ordered (a stable core); + = more flexible.
  • V_T · terminal / exposure — chain-end + solvent exposure. − = more buried / central; + = more exposed / peripheral.
  • V_R · rigidity — high contacts + clustering, low fluctuation. + = a rigid hub; − = floppy.
  • V_C · dynamic coupling — how correlated its motion is with the rest. + = a communication hub (allosteric signal carrier); − = dynamically isolated.
  • V_M · slow-mode participation — share in the slowest collective motions. + = drives global hinge/domain motion; − = in the static body.

Contact-Laplacian spectrum (λ): the network's vibrational modes. Low λ (near 0) = slow, large-scale collective motions (hinges / domains) — these carry allosteric signals over long range; lots of low-λ density (a small “spectral gap”) means a softer, more deformable network. High λ = fast, local fluctuations. (One λ≈0 per connected chain.)

Connectivity change apo→holo (DDM · rewiring · ΔDCC + morph)

How the residue network reorganizes when the drug binds (topology only, no MD). DDM = distance-difference matrix (red = move apart, blue = move closer); rewiring = contacts formed (+1) / broken (−1); ΔDCC = change in dynamic cross-correlation (the coupling that underlies allosteric communication). Overlay lines: teal = active site, purple = drug-binding residues.
