## Findings

### P2

- **TASK-0004's committed Planned Validation is short one test.** The task's
  own Intent Contract states: "one integration test gated behind network
  access (`@pytest.mark.network` or similar) against KRAS_G12C (4OBE/6OIM)
  once TASK-0003's config exists." No such test exists in
  `tests/test_labels.py`. The module docstring for
  `ligand_groups_from_atomgroup`/`protein_heavy_atoms_by_residue`
  (`labels.py:56-67`, `labels.py:99-104`) narrates a real check that was
  apparently run once by hand ("Confirmed against a live fetch (TASK-0004
  KRAS_G12C integration check, 2026-07-06)... 9/21 ... recovered"), but that
  check isn't a re-runnable committed test the way TASK-0005's
  `test_kras_g12c_real_target_expects_low_cumulative_overlap` is. The
  9/21-recovery number and the alignment-correctness claim currently rest on
  an unreproducible one-time run.
  - Evidence: `labels.py:56-67`, `labels.py:96-104`; `tests/test_labels.py`
    (grep for `network`/`prody`/`KRAS` finds only docstring references, no
    test function).
  - Impact: if `labels.py`'s alignment or heavy-atom contact logic
    regresses, nothing in CI would catch it against a real structure — only
    the synthetic-coordinate unit tests would run.

### P3

- **`test_numbering_offset_still_maps_correctly` doesn't stress what its name
  implies.** `holo_pocket_mask`'s alignment path (`labels.py:278-330`) never
  reads `apo.resnums`/`holo.resnums` values at all — only `.resnames` (for
  sequence content) and array length. The test shifts `holo_resnums` by +19
  but keeps sequences identical, so the Needleman-Wunsch alignment trivially
  recovers a 1:1 index map regardless of the offset; the test can't
  distinguish "offset handled correctly" from "resnum values ignored
  entirely" (which is actually true, and stronger than requested — but no
  test exercises the aligner on a real indel/gap case to confirm the
  alignment logic itself, not just the offset-indifference, works).
  - Evidence: `labels.py:278-330` (no `resnums` read in the body);
    `tests/test_labels.py:123-135`.
  - Impact: low — the underlying design (numbering-independent, pure
    sequence-position mapping) is sound and matches intent; this is a test
    naming/coverage clarity gap, not a code defect.

  covers this per-target.
- **CARDIAC_MYOSIN's partial dequarantine is deliberate and test-pinned**, not

  false`), but the apo 5TBY IHM-assembly concern is kept open in `warnings`

  `holo_pocket_mask` maps via global Needleman-Wunsch over sequence content

  backend" __WORK_IN_PROGRESS__/src/` returns zero real imports (only
  docstring mentions) — the "port, don't import across `backend/`↔`allostery/`"
  constraint holds.
- **Relaxation time, not underdamped period, is reported** —
  `mode_energetics` (`superpose.py:378-406`) computes `tau_k = zeta / (kappa *
