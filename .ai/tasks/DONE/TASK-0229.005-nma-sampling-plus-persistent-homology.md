**Implementation, reusing existing infrastructure**: `ensemble_void_score`
added to `allostery.persistent_voids`, factored out of the existing
single-structure `void_score` (`_score_from_dgm2`, shared shell-kernel
geometry) so both paths share one implementation, not two. One `ripser`
call per conformation, not two — H1's top lifetime is read from the same
call already computing H2, as a secondary diagnostic only (this module's
own docstring: a capped cavity is an H2 void, not an H1 loop — H1 is not
scored into a residue ranking here, just reported per-conformation).

**Real bug found and fixed while building this** (surfaced by the
ensemble path running ~100x more `ripser` calls than any single-structure
caller ever had, but latent in the original single-structure code too):
a persistence class still alive at the Rips filtration cap `thresh` gets
`death=inf` from `ripser`, so its raw "lifetime" is `inf` and always won
top-k selection over any real, finite void, propagating NaN into the
shell-kernel score. First fix attempted (exclude non-finite deaths)
flipped two long-passing synthetic-fixture tests from pass to fail —
revealing those tests' own `>3.0` checks had themselves been passing on
`inf > 3.0`, not on a measured finite lifetime. Correct fix: right-censor
at `thresh` (`_censor_deaths`) rather than exclude — a class still open
at the observation limit is *at least* as persistent as `thresh - birth`,
not "no signal." Applied to `void_score`, `top_h2_persistence`, and
`ensemble_void_score` alike. **Checked for retroactive impact on
TASK-0142's own previously-published real-target numbers**: re-ran
`top_h2_persistence` post-fix on all 3 of that task's own apo targets —
KRAS_G12C 0.6694, BCR_ABL1 2.4042, CARDIAC_MYOSIN 2.8289, all matching
that task's own recorded values to full float precision. The bug was
never actually triggered on those 3 real structures; no correction to
TASK-0142's own record is needed. 2 new tests added
(`tests/test_persistent_voids.py`), 4 pre-existing tests re-verified
passing unchanged.

New `scripts/task0229_005_nma_persistent_homology.py`: reuses
`task0229_004_zheng_nma_baseline.per_mode_displacements` verbatim (same
N_MODES=20/AMPLITUDES/kT=20.0), so this arm's NMA-sampled ensemble is the
literal same displacement set .004's fpocket arm scored — only the
pocket-detection layer changes (fpocket → persistent homology). No
full-atom reconstruction needed (persistent homology runs directly on Cα
coordinates, `persistent_voids.py`'s own existing convention) — much
cheaper than .004's fpocket-subprocess arm: ~5-9s per 120-conformation
target vs. .004's ~52-54s.

**Planned Validation (this task's own Constraint) — FAILED, on both
VALID targets.** `void_score` computed directly on the HOLO structure
(already open, no sampling needed — the best-case single structure for
detecting a void): KRAS_G12C top H2 persistence 0.812 (this project's own
established noise floor is 2.5, `test_solid_ball_has_no_strong_void`),
AUC against the known pocket 0.557 (barely above chance). PTP1B: top H2
persistence 1.535 (also sub-floor), AUC **0.116 — anti-correlated** with
the known pocket. Confirmed not a filtration-cap artifact: both targets'
`top_h2_persistence`/AUC are numerically identical at thresh=16, 20, 24,
30 — the relevant persistence classes already close well inside the
smallest cap tried. 14 (KRAS_G12C) / 24 (PTP1B) H2 classes exist in each
structure at all (small sampling-noise-scale cavities, consistent with
the synthetic solid-ball baseline), none reaching the noise floor, none
concentrated near the known pocket.

**Per this task's own gating** (apo-ensemble scoring conditioned on its
own target's holo positive control passing — a target-specific gate,
stricter than a single shared validation target): **both VALID targets
skipped as trusted scores.** Run anyway as an explicit **ungated
diagnostic**, for transparency, per the same gated/ungated convention
`persistent_voids_real_run.py` already established for this observable:
120-conformation NMA-sampled apo-ensemble AUC 0.521 (KRAS_G12C, floor
0.530 — does not beat it) / 0.487 (PTP1B, floor 0.451 — nominally beats
it but compact-patch null p=0.63, nowhere near significant). Only 5% of
sampled conformations, on either target, ever cross the noise floor at
all (`frac_conf_void_detected=0.05`). Consistent, not contradictory, with
the failed positive control: an ensemble of apo displacements sampling
toward "openness" cannot manufacture a topological feature the true open
(holo) structure itself does not have.

**Comparison against TASK-0143's proxy (this task's own Constraint)**:
genuinely different observables, not two readings of the same thing — as
`persistent_voids.py`'s own module docstring already states, TASK-0143
tested whether pocket residues are Euclidean-near but graph-hop-far on
the apo contact graph (a structural-graph question); this task tests
whether the pocket sits inside an actual persistent H2 cavity (a
topological question) — a pocket can fail one and pass the other. On
these same 2 targets: TASK-0143 found KRAS_G12C **INSUFFICIENT** (98.4th
percentile, uncorrected p=0.016, not Bonferroni-significant) and PTP1B
**INFEASIBLE** (its matched-spread null could not be constructed at all
via rejection sampling — no verdict possible). This task reaches a
**decisive negative on both**, including the one (PTP1B) TASK-0143's own
methodology could never resolve — H2 is testable where the graph-openness
proxy was not, and the answer here is a clean no, not an open question.
Register-level implication for this refile's own "revives the H2 arm"
framing: it is revived in the sense of being *properly tested* for the
first time (TASK-0142 was apo-only, single-structure, no positive
control, and TASK-0143 could not test this observable at all) — not in
the sense of finding a positive. The family is now tested, not
resurrected as a live lead.
