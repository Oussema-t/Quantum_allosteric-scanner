- Priority: **P1 — the largest genuinely untested item in the bibliography.**

## Why, precisely
The register is careful here and the care matters. A **harmonic proxy** of
ensemble coupling was tested 2026-08-21 and lands in the same confounded room
as everything else (|partial ρ| = 0.773 on non-target structures). So the
ensemble route is **not** an exit we walked past.

But the **genuine EAM — binary folded/unfolded units, nonlinear, non-Gaussian —
is untested.** Harmonic stiffening is not unfolding. That is the live residual,
and it matters for three reasons:

1. **COREX-style ensembles are MD-free** (sliding-window folding units,
   ASA-parameterised ΔG per microstate, residue stability constants κ_f),
   therefore Constraint-3 compliant and computable from a static PDB.
2. It is the **only route to c-Myc/Max (1NKP)** — via H4.3, disorder amplifies
   allosteric coupling — and c-Myc is in the mandated minimum target set with
   no other viable approach.
3. It is the **type-correct quantum target**: partition-function estimation /
   Gibbs-state preparation over 2^N microstates. That converges independently
   on this program's own conclusion that hardness lives at the combinatorial
   layer, not in the propagator.

## Intent Contract
- Outcome: a COREX-style ensemble coupling score on KRAS_G12C and PTP1B, scored
  under standard conventions, plus a decisive comparison against propagation
  ranking.
- In Scope: sliding-window folding units; ΔG per microstate; κ_f; score =
  response of κ_f at the active site to perturbation at candidate site j.
- **Decisive negative control (the register's own, and it is the right one):**
  construct the case where EAM ranking and propagation ranking **disagree**.
  If they agree everywhere, EAM adds nothing here and that closes it.
- Out Of Scope: **any advantage claim.** Quantum speedups for classical
  partition functions are at best quadratic and conditional. Claim
  *type-correctness* only.
- Constraints: this is the one route with a live path to c-Myc — but c-Myc has
  no holo structure, so no validation is possible there. Do not let an
  unvalidatable target become the headline.
- Planned Validation: κ_f must reproduce known stability behaviour on a
  well-characterised control before any coupling number is trusted.

## Done

**2026-08-23.** Built, validated, and run on both TASK-0209-VALID targets.
Real, mixed result — not a clean "EAM adds nothing" closure, not a clean
"EAM is independent of propagation" finding either.

**Implementer's-call simplification, stated in the code itself, repeated
here**: the full COREX method (Hilser & Freire 1996) fits ΔCp/ΔH/ΔS
separately from polar/apolar ASA via several empirical constants (Murphy
& Freire 1992 and descendants) and extrapolates across temperature. This
task's own scope ("ASA-parameterised ΔG per microstate," not "reproduce
Hilser/Freire's own published numbers exactly") was read as license for a
simpler, single-temperature two-term model instead:
`dG_unfold(window) = 18 cal/(mol·Å²) × (newly-exposed apolar ASA)  −
298.15 K × 4.1 cal/(mol·K) × n_residues`. The apolar-burial coefficient
is Eisenberg & McLachlan 1986 (*Nature* 319:199, doi:10.1038/319199a0,
bibliographically verified — title/authors/journal/DOI independently
confirmed; the paper's own finer per-atom-type parameter table was not
re-checked digit-by-digit, paywalled). The unfolded-reference ASA table
is Tien et al. 2013 (*PLoS ONE* 8:e80635, doi:10.1371/journal.pone.0080635,
bibliographically verified) — **the 20 per-residue-type numeric values
used are the widely-reproduced ones, not independently re-OCR'd against
the paper's own table image**, flagged rather than silently presented as
primary-source-checked. The 4.1 cal/(mol·K·residue) backbone entropy term
is a standard order-of-magnitude estimate (~R·ln(few) accessible backbone
states per residue), not D'Aquino et al. 1996's own fuller per-residue-
type table. New `allostery/corex.py` — ASA via BioPython's own validated
`Bio.PDB.SASA.ShrakeRupley` (not re-implemented), sliding-window folding
units (COREX's own practical O(N·W) approximation to the intractable
full 2^N combinatorial powerset), per-residue κ_f, and a perturbation-
based coupling score.

**Sanity check (Planned Validation, real and passing on both targets)**:
buried (low-ASA) residues must show higher κ_f than exposed (high-ASA)
residues.

| target | Spearman ρ(native ASA, log₁₀ κ_f) | p | buried mean log₁₀κ_f | exposed mean log₁₀κ_f |
|---|---|---|---|---|
| KRAS_G12C | −0.365 | 1.06×10⁻⁶ | 6.01 | 3.69 |
| PTP1B | −0.298 | 1.61×10⁻⁷ | 3.95 | 2.75 |

Both real, decisive, correctly-signed (more exposed → less stable, as
expected) — the model is not degenerate and is trusted for the next step.

**Coupling score + decisive negative control**: for every residue j,
"stabilise" j (a `stabilization_bonus` penalty on any window overlapping
j, mimicking ligand binding locking that region folded) and measure the
resulting shift in the whole active site's own aggregate ΔG_f (treated as
one fused region — a scope simplification from the per-active-site-
residue profile `corex.coupling_score` itself also supports and was
spot-checked against, see caveat below). Ranked every residue by this
coupling score, then compared that ranking against this project's own
established propagation-based baseline (hop-distance from the active
site, `baselines.hop_from_seed`) via Spearman correlation — the task's
own "does EAM ranking disagree with propagation ranking" test:

| target | EAM-vs-propagation Spearman ρ | p | top EAM-coupling site(s) |
|---|---|---|---|
| KRAS_G12C | **0.542** | 2.7×10⁻¹⁴ | 45-50 (a contiguous cluster) |
| PTP1B | **0.493** | 1.1×10⁻¹⁹ | 161-165 (a contiguous cluster) |

**Neither closure the task's own decision rule anticipated.** ρ≈0.5-0.54
is real, highly significant, substantial agreement with propagation —
EAM is not an independent signal from proximity — but it is far short of
the ~0.85-0.95-type agreement this register's *other* observables show
with proximity baselines when they turn out to just be distance detectors
in disguise (see [[TASK-0226]]). Roughly 70-75% of the EAM ranking's own
variance is **not** explained by hop-distance alone. Read plainly: EAM
correlates with propagation more than chance, less than redundancy — a
genuinely mixed result, reported as such rather than forced into either
of the task's own two pre-registered bins.

**Caveat on the coupling metric itself, found and not smoothed over**:
the aggregate whole-active-site-region ΔG_f used for the ranking above
and the per-active-site-residue profile `corex.coupling_score` itself
also computes are **different quantities** (a region-level fused
measurement vs. per-residue individual measurements) — spot-checked
directly, confirmed they do not numerically coincide, and the per-
residue profile shows some non-intuitive behaviour of its own (near-zero
values for most active-site residues, two large negative outliers on
KRAS_G12C at residues 59/60) not fully diagnosed within this task's own
time budget. The aggregate metric is what the ranking/correlation above
is built on and is internally consistent on its own terms; the per-
residue profile is available in the library but its own interpretation
is flagged open, not resolved.

**Forward-proposal write-up (type-correctness, explicitly not
advantage)**: this remains, as the register already concluded before any
number here existed, a partition-function-over-2^N-microstates estimation
problem — Gibbs state preparation / partition function estimation is a
real, type-correct quantum target (amplitude estimation over a Boltzmann-
weighted ensemble), independent of what this task's own real numbers
show. **Nothing in this task's own result changes that framing, and
nothing in it licenses a speedup claim** — the ensemble here (O(N·W)
windows, a few hundred to a few thousand states) is itself classically
trivial to enumerate; the type-correctness argument is about the
*combinatorial* microstate space COREX approximates away for
tractability (the true 2^N space), not about this task's own tractable
approximation of it. Any future quantum-Gibbs-sampling proposal built on
this work must state that distinction explicitly, per this task's own
Out Of Scope.

**HYP-P13 cross-reference** (`physics.md` names this task explicitly as
its own decisive test): this task's own result is **inconclusive** for
HYP-P13, not supporting or refuting it decisively. HYP-P13 predicts EAM
ranking should meaningfully diverge from a pure propagation picture on at
least some real targets; ρ≈0.5 is genuine partial divergence (not the
~0.85-0.95 "basically the same signal" pattern this register's other
observables show), consistent with *some* real ensemble-specific
information — but not the clean disagreement case that would make HYP-P13
decisively favoured over a propagation-only picture either. HYP-P13's own
"Status: open, unowned as a whole" stands unchanged by this task.
