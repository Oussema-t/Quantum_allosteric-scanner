## Intent Contract

- Outcome: a function, e.g. `analysis.assemble_verdict_results(benchmark,
  ablation, qvc, consistency) -> dict`, that takes the real return values
  of `benchmark()`, `ablation()`, `quantum_vs_classical()`, and
  `apo_holo_consistency()` and produces exactly the flat dict
  `verdict_template` expects — real values, not the test fixture's
  hand-picked ones.
- In Scope:
  - read `analysis.py`'s actual return shapes directly (not from memory
    or this task's own paraphrase) before writing the mapping:
    `benchmark()` → `{"H_new_default": metric_pack,
    "H10_disorder_suppressed": metric_pack}` where each `metric_pack` has
    an `"AUC"` key (from `_metric_pack`); `ablation()` → per-term dicts
    keyed by dropped term; `quantum_vs_classical()` → `{"ctqw": {...},
    "heat": {...}}` each a metric pack; `apo_holo_consistency()` →
    `{"spearman_rho": ..., "top_k_jaccard": ...}`.
  - map each to its `verdict_template` key: `AUC_apo_Hnew_default` ←
    `benchmark["H_new_default"]["AUC"]` (apo role — confirm `benchmark`'s
    actual role handling, it may need an apo/holo split not visible from
    the signature alone); `AUC_apo_H10_baseline` ←
    `benchmark["H10_disorder_suppressed"]["AUC"]`; `AUC_ctqw_mean`/
    `AUC_heat_mean` ← `quantum_vs_classical`'s two packs' `"AUC"` values;
    `most_impactful_term`/`least_impactful_term` ← derived from
    `ablation()`'s per-term deltas (largest/smallest absolute effect,
    same convention the notebook's cell 58 used, already cited in
    `report.py`'s own module docstring); `mean_rho_apo_holo`/
    `mean_jacc20` ← `apo_holo_consistency()`'s `spearman_rho`/
    `top_k_jaccard`, averaged across whatever set of runs the caller
    supplies (single-run vs. multi-run averaging is this task's design
    call — document the choice).
  - `AUC_apo_Hnew_optimised`/`AUC_holo_Hnew_optimised`: these come from
    the *optimized*-parameter run, not `benchmark()`'s default-parameter
    comparison — confirm whether an existing function produces this or
    whether `.003` (the FROZEN-gated pipeline) is expected to supply it
    directly; don't invent a new optimization step here if one doesn't
    exist yet.
  - unit tests: call the real `analysis.py` functions on a small
    synthetic structure (reuse `test_analysis.py`'s existing fixtures),
    feed the real output into the new assembly function, assert every
    `verdict_template`-expected key is present with a real (not
    hardcoded) value, then feed the assembled dict into
    `verdict_template` itself and confirm it renders without a missing-key
    "N/A" for any of the ten keys.
- Out Of Scope: `report.verdict_template` itself (already correct, per
  TASK-0088 — do not modify); the FROZEN-gating/provenance-stamping
  around this assembly (that's `.003`'s job — this subtask's function
  should be a pure, ungated transformation, callable on any already-
  computed `analysis.py` output regardless of DEV/FROZEN state).
- Constraints And Invariants: pure function, no I/O, no `protocol.py`
  dependency — keeps this subtask independently testable without needing
  a `frozen_context` at all.
- Planned Validation: the seam-test above (real `analysis.py` output →
  assembly → `verdict_template`, no missing keys); update
  `.ai/seams/SEAM-0008-analysis-report-schema-assembly.md` to `VERIFIED`
  once it passes.

## Done

- 2026-07-12, Implementer A. Added `analysis.assemble_verdict_results(
  benchmark_out=None, ablation_out=None, qvc_out=None, consistency_out=None,
  *, auc_apo_optimised=None, auc_holo_optimised=None) -> dict` in
  `analysis.py` (placed right after `benchmark()`, before the Sec.12
  apo/holo-consistency section, per this task's own recommendation).
- Resolved the Open Question: `AUC_apo_Hnew_optimised`/
  `AUC_holo_Hnew_optimised` are **not** derived from `benchmark()` (which
  is explicitly the default-parameter comparison) — they are accepted as
  direct optional keyword args, to be supplied by `.003`'s
  `select_frozen_config`-driven pipeline. Confirmed by re-reading
  `benchmark()`'s own docstring/body in full before writing the mapping.
- `most_impactful_term`/`least_impactful_term`: computed from
  `ablation_out`'s per-term AUC delta against `"L_only"` (largest/
  smallest absolute delta), formatted with the codebase's `"V_"` term
  prefix (`potentials.py` convention) — not the bare single-letter keys
  `ablation()` returns.
- `mean_rho_apo_holo`/`mean_jacc20`: pulled straight from a single
  `apo_holo_consistency()` call's `spearman_rho`/`top_k_jaccard` (no
  multi-run averaging implemented — out of scope, no multi-run caller
  exists yet; `.003` calls this once per target).
- Every argument is independently optional; a key is omitted entirely
  (not set to `None`/`"nan"`) when its source value is missing or
  non-finite (`metrics.auc()`'s degenerate-labels `NaN` convention) —
  `verdict_template` then renders `"N/A"` for it, never the literal
  string `"nan"`.
- Tests: `test_analysis.py::TestAssembleVerdictResults` (6 cases) — full
  assembly populates every `verdict_template` key with a real value; the
  rendered report has no `"N/A"`; `most_impactful_term`/
  `least_impactful_term` are `"V_"`-prefixed and never `"V_L_only"`;
  every argument is independently omittable (`assemble_verdict_results()`
  returns `{}`); `auc_*_optimised` pass through unchanged, not derived
  from `benchmark`; an all-same-label `benchmark` (NaN AUC) omits the key
  and the render contains no `"nan"` substring.
- Validation: `python3 .ai/tools/pytest_local.py wip-all --json` — 440
  passed, 1 xpassed, 0 failed.
- Updated [[SEAM-0008]] to `VERIFIED`, pointing at the new test class as
  the seam-test.
