## The claim, and why it is dangerous to us
Ref [9] argues nearly every dynamic protein has latent allosteric capability —
**there is no clean class of "non-allosteric" surface sites.**

Every AUC in this register presupposes the opposite. Matched-decoy nulls,
setup-validity gates and all ROC framing treat non-functional surface pockets
as true negatives. If [9] holds, that premise is unsound, and it cuts **both**
ways: it inflates apparent false positives, *and* it means a chance-level AUC
is no longer evidence of no signal.

That second direction matters enormously here, because the program's entire
headline is built on chance-level AUCs.

**(c) Multiplicity-budget consequence, reasoned through explicitly, not
asserted.** Two separable questions: does ref [9] change the *arithmetic*
(TASK-0161/TASK-0199's 226-cell count, ~2 expected false positives after
the ~9× redundancy correction, 0 confirmed) — no, that is a count of how
many cells cleared a significance bar against how many chance predicts,
which does not depend on whether the negative class is clean. Does it
change the *interpretation* of that zero — yes: a contaminated negative
class is an equally consistent explanation for the same zero (reduced
statistical power from noisy negatives masking a real, weaker signal),
and this program's methodology as built cannot distinguish that from a
genuine absence of coupling. Resolved conclusion, matching the task's own
"state either way": the multiplicity frame itself is still the right one
to report (the count is real and worth stating), but the program's own
claim must be phrased as "no method tested here found a statistically
robust signal," not "we have shown there is no signal" — written into
§2.5 verbatim.
