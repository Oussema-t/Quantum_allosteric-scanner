## Two separable items

**[15] Two-state ANM — the instrument to *quantify* [[TASK-0209]].**
TASK-0209 asserts 2/7 targets are valid via a druggability-contrast rule. A
two-state ANM gives a *principled, continuous* measure of how well an apo↔holo
transition is captured by the elastic-network model — turning "valid / invalid"
into a graded quantity with a mechanism. That would strengthen the register's
single most-cited finding considerably.

**[7] Non-equilibrium energy transport — the whole pipeline is equilibrium.**
Every observable in the register is an equilibrium quantity. Ref [7] frames
allosteric communication as non-equilibrium energy transport following a local
perturbation. **ENM impulse response is closed-form and MD-free**, so this is
testable within Constraint 3, and it is a genuinely different observable class
rather than a 29th view of the same one ([[TASK-0199]]).

**Planned Validation (whole-structure CO(50), KRAS_G12C > BCR_ABL1):
FAILS** — 0.766 < 0.858. This is the task's own explicitly-anticipated
possible outcome ("or the instrument disagrees with the finding it was
meant to quantify — itself a result worth reporting"), not a bug: larger,
more flexible structures (BCR_ABL1 429 residues, CARDIAC_MYOSIN 698) show
higher whole-structure CO almost regardless of functional relevance — CO
over the full structure is confounded with size/flexibility, not a clean
readout of TASK-0209's druggability-contrast rule.

Built a pocket-restricted variant in response (`restricted_cumulative_overlap`,
TASK-0133's Bessel-valid form for a small residue subset, not the
whole-structure renormalized-slice approach) to ask the more targeted
question TASK-0209 actually asks — does the *pocket itself* move along
the dominant apo→holo deformation. **Planned Validation, pocket-restricted
(KRAS_G12C > BCR_ABL1): PASSES** — 0.547 > 0.316 — but this is not a
clean full 7-target separation: GLUCOKINASE (INVALID) scores 0.676,
above both VALID targets. Read plainly: the pocket-restricted variant
recovers the one specific pre-registered comparison but does not
generalize to a clean instrument across all 7. CASPASE7's pocket-
restricted CO could not be computed — diagnosed directly (not assumed):
`labels_obj.pocket & in_common` is empty, i.e. CASPASE7's labeled pocket
residues have zero correspondence in the apo/holo alignment, a real
data/alignment gap specific to this target, reported rather than
silently worked around.

**(b) ENM impulse-response transport** (`src/allostery/impulse_response.py`,
ref [7] Stock & Hamm 2018, doi:10.1098/rstb.2017.0187). Closed-form
finite-time GNM dynamic cross-correlation, `C_ij(t) = Σ_k (1/λ_k) U_ik
U_jk exp(-λ_k t)` — the same static-GNM-covariance physics
`allostery.potentials.gnm_context` already uses, extended to t>0;
verified `C(t=0)` exactly reproduces the register's own existing static
covariance (`test_impulse_response.py::test_t0_matches_static_gnm_covariance`,
abs=1e-8). Two candidate observables were checked directly, not assumed,
before picking one: `peak_time` (time-to-max response) was found
degenerate on a real target — 67% of KRAS_G12C's 169 residues peak at
t=0, only 14 distinct values — so `integrated_response` (∫|C(t)|dt,
continuous, 169/169 unique values, Spearman ρ=−0.25 vs peak_time on the
same target — genuinely different information) was used as the primary
observable for the independence test, with `peak_time` kept as a
secondary diagnostic.
