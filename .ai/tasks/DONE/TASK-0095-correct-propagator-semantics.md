# TASK-0095 Correct propagator semantics (`heat` on indefinite `H_new` is not classical diffusion)

## Context

- ID: TASK-0095
- Title: Rename `heat` → `ground_state_relaxation` (or equivalent); guard
  against feeding an indefinite operator into any diffusion-semantics
  path; correct all downstream framing in `RESULTS.md`/`report.txt`/the
  methodological report.
- Status: Done
- Owner: Implementer
- Source: `__WORK_IN_PROGRESS__/REVIEW-2026-07-13-proximity-confound-and-propagator-semantics.md`,
  finding **P1-B**. Executed against real `build_H_new`: its spectrum is
  indefinite (min −1.833, max 10.155), yet `heat()`'s own docstring
  (`propagators.py:85`) states *"H should be a positive-semidefinite
  Laplacian."* `‖exp(-H·20)·p₀‖₁` before the internal clip/renormalize is
  **1.75 × 10¹³** (a conservative diffusion process would hold this at
  1.0). `Spearman(heat(H_new, t=20), |ground state|²) = 0.998` — `heat()`
  is returning the ground-state density of `H_new`, not diffusing
  anything; the clip-and-normalize step masks a 13-order-of-magnitude
  divergence.

### Two serious, separate downstream consequences

1. **`RESULTS.md`'s BCR_ABL1 headline is mis-framed.** "Classical heat
   0.731 vs CTQW 0.525" is not a classical-vs-quantum comparison — it is
   "the ground state of `H_new` localizes differently than the
   time-averaged walk." Every place this appears currently makes a false
   physical claim and must be corrected.
2. **TASK-0091 (as originally filed) rested on a false premise.** The
   Haken–Strobl γ→∞ limit is a classical random walk generated by the
   *off-diagonals*; `heat(H_new)` is dominated by the *diagonals*. The
   dephasing sweep is structurally incapable of converging to
   `heat(H_new)` — it cannot "recover" 0.731, and if AUC happened to rise
   under a dephasing sweep, attributing it to ENAQT would have been an
   unsupported causal claim. TASK-0091 has been re-filed (see that task)
   to test the real, distinct question directly.

## Intent Contract

- Outcome: (a) `propagators.heat` renamed to something that states what
  it actually computes (e.g. `ground_state_relaxation`) — update every
  call site; (b) a guard raising, or emitting a loud diagnostic, whenever
  `min(eigvalsh(H)) < -tol` is passed into any function whose semantics
  assume a positive-semidefinite (diffusion-generating) operator, so an
  indefinite operator can never again be silently treated as a diffusion
  generator; (c) every downstream artifact that currently frames the
  BCR_ABL1 heat-kernel number as "classical diffusion" or
  "classical-vs-quantum" is corrected to the accurate framing (ground-state
  localization of `H_new`, not a diffusion process).
- In Scope: `propagators.py` (rename + guard), every call site
  (`analysis.py`, `report.py`, orchestrator code from TASK-0079.x),
  `RESULTS.md`, any generated `report.txt`, the methodological report
  template.
- Out Of Scope: deciding whether ground-state localization is a useful
  signal (that's TASK-0091, re-filed, gated on TASK-0094's proximity
  floor) — this task only fixes the naming/guard/framing, not the
  scientific question of whether the number means anything.
- Acceptance Scenarios:
  - Given `build_H_new`'s real indefinite spectrum, when the renamed
    function runs, then no docstring or call site claims it is a
    diffusion/Laplacian-semantics process.
  - Given an indefinite `H` passed to any diffusion-semantics-assuming
    path, when that path runs, then it raises or loudly diagnoses rather
    than silently clipping/renormalizing a divergent intermediate.
  - Given `RESULTS.md`'s current BCR_ABL1 write-up, when corrected, then
    it states plainly that 0.731 is a ground-state-localization score on
    the same operator, not a classical-diffusion comparison.
- Constraints And Invariants: do not change the *numeric* output for
  operators that are genuinely positive-semidefinite (e.g. `H8_gnm`,
  plain contact-matrix Laplacians) — this is a semantics/naming/guard
  fix, not a behavior change for the cases where the function's original
  assumption already held.
- Planned Validation: a test asserting the guard fires on `build_H_new`'s
  real indefinite spectrum and does not fire on a genuine PSD Laplacian
  (e.g. `H2_combinatorial_laplacian`); a grep-based check that no
  remaining doc/report artifact uses "classical diffusion" language for
  the renamed function's output.
