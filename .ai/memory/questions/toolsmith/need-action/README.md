Questions for the Toolsmith role move here once answered, when the answer implies
someone must still *do* something (file a task, change a tool, update a convention) —
not just read the answer. Stays here until that action is taken, then moves to
`../answered/` with a note on what was done, or a link to the `TASK-XXXX` file that now
owns the follow-through. See `.ai/memory/questions/README.md` for the full convention.
